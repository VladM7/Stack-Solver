# Contributing to Stack Solver

First, thank you for your interest in contributing to Stack Solver. 

The purpose of this project is to provide an open-source alternative to already existing (closed source, possibly expensive) solutions. Therefore only with the community's help it can compete with other professional-grade software, so all contributions are welcome and encouraged!

## How to contribute

For anything bigger than a one-line fix:

- Create your own fork of your code
- Do the changes in your fork
- If you think the main project would benefit from your changes, make a pull request!

### Pull request checklist

- Code builds successfully
- Existing behaviour is not broken
- Documentation is updated, if needed
- PR has clear descriptions

## How to report a bug

If you found a bug, open an issue with:

- Expected behaviour
- Actual behaviour
- Steps to reproduce
- Screenshots and logs, if relevant

## How to suggest a feature or improvement

First, take a look at the roadmap section of [`README.md`](README.md). The feature may be already planned or work in progress. If not, open an issue which describes the feature you would like to see, why you need it and how it should work.
